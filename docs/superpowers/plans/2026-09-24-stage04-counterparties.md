# 第 04 段：往来单位建档与编辑

范围：R04-01～R04-06、R06-01～R06-07、R07-01～R07-07。依赖已验收的会话权限（02）和写入幂等（03）。

## 验收目标

- 销售只能建档、查看、编辑自己负责的客户；采购同理处理供应商；对应主管可处理本岗位团队，老板及管理员可处理全部。归属由已登录身份和真实用户目录校验，接口不能通过伪造请求体或筛选参数越权。
- 主要字段直接展示，次要字段可展开；新增和编辑后能看见正确数据，编辑成功短暂提示并自动收起。
- 入库时间只读；字段标签、付款方式、结算方式、单位标签、金额及模具费用遵循需求，空值合法，金额非空时合法。
- 老板/管理员配置往来单位自定义字段（文字、数字、日期）；最多 10 个活动字段，删除二次确认，已删除字段普通页面/API 不再显示但旧值保留。
- runtime / Prisma 都可持久化；Prisma 使用增量迁移，不改历史单据。

## 步骤

- [x] API：角色、归属、用户目录及只读查询权限，补越权测试。

> 实际结果：列表与正式查询按所属人员和岗位筛选；新增、编辑在接口校验类型、原负责人和目标负责人，并以登录会话记录操作人。重复真实姓名的在职用户不可分配，避免归属混淆。

- [x] 数据：固定字段、自定义字段定义和值、软删除，runtime / Prisma 与迁移，补业务测试。

> 实际结果：新增字段与自定义值在两种存储路径实现；删除只标记字段，旧值保留但普通列表、详情和审计接口不再返回；Prisma 提供增量迁移。未连接真实 MySQL 执行迁移。

- [x] 页面：精简列表、折叠表单、负责人选择、新字段、自定义字段管理、成功反馈，补交互测试。

> 实际结果：主要字段直接展示，其余字段折叠；新增和编辑即时更新列表，编辑成功后收起表单并短暂提示；字段管理仅老板、管理员可见。

- [x] 验证：定向测试、`make ci`、可用时本地页面关键流程；记录限制，完成后等待验收。

> 实际结果：`make ci` 通过（shared 41、web 363、api 519 项），`prisma validate` 通过；隔离 runtime 服务中用销售 Zoe 完成新增与编辑、核对所属人员固定为本人，用老板 Mia 建立自定义字段并核对持久化。真实 MySQL 与生产部署未验证，本段停止等待页面验收。
