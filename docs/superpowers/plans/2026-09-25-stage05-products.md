# 第 05 段：产品库查看与建档

范围：R09-01～R09-06、R03-05。依赖已验收的会话权限、写入幂等及往来单位自定义字段。

## 验收目标

- 销售从左侧“产品库”进入列表，能看到完整产品编码和销售资料；页面与产品列表、正式产品选择接口均不返回采购价、采购编码、供应商资料，且不能新增、编辑或配置字段。
- 管理员从列表的“新增”按钮打开弹窗，在弹窗完成现有产品建档流程；保存成功后弹窗关闭，列表显示新产品。采购编码可留空。
- 老板、管理员可配置最多 10 个产品自定义字段（文字、数字、日期）；产品新建和编辑可保存其值。删除确认后字段不再在普通页面/API 出现，旧值保留在存储中。
- “销售编码”在产品库页面改称“产品编码”；原销售编码规则允许配置供应商编码段，生成值仍为完整编码。新规则仅作用于后续生成，历史产品编码不改写。
- runtime 与 Prisma 均持久化自定义字段及产品值；Prisma 提供增量迁移。

## 步骤

- [x] 权限与脱敏：产品列表和正式产品选择接口按登录角色返回字段，写入和字段配置在接口限制角色；补越权与销售脱敏测试。
  > 销售查看两个接口时采购编码、采购价、供应商资料及自定义值均不返回；实测销售 POST 产品接口返回 403。
- [x] 数据：产品自定义字段定义、值、软删除、runtime / Prisma 和迁移；补存储测试。
  > 增量迁移新增字段定义表和产品自定义值 JSON 列；runtime 与 Prisma 测试覆盖删除后旧值保留、普通读取隐藏。
- [x] 编码：销售规则允许供应商编码段，生成时使用当前产品供应商编码；采购编码可空；补规则与建档测试。
  > 新建产品实测采购编码留空可保存；编码预览改为当前日期，历史产品编码未改写。
- [x] 页面：左侧入口、销售只读列表、新增弹窗、产品自定义字段管理与值输入、标签调整；补交互测试。
  > 浏览器以管理员新建和编辑产品，自定义值刷新后回显；新增并删除临时字段，确认弹框和 10 个名额计数正常；以销售查看新产品，仅见完整产品编码和销售资料。
- [x] 验证：定向测试、`make ci`、可用时在本地页面走关键角色与操作；记录实际结果，等待本段验收。
  > `make ci` 通过：shared、api、web 构建与测试全绿（API 103 套/524 例，Web 70 套/365 例）。浏览器验证使用本机 3100/3101 runtime 演示环境；未连接 MySQL 做实际迁移部署，Prisma 路径由单元测试覆盖。
