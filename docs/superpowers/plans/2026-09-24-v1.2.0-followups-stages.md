## 基线与执行约束

- 2026-09-24 核实：原分支 `main`，HEAD `0cf42df`，与 `v1.2.0` 标签完全一致；根 package.json 的 1.0.0 不是本次发布版本依据。
- 开始时只有未跟踪的 `docs/requirements/`，没有已修改或暂存的代码。保留需求文件原样。
- 当前开发分支：`codex/v1.2.0-stage-06-inquiry-to-sales`，在用户指定项目目录开发；第 06 段基线提交为 `d8800a1`。
- 每段交付后停止，收到用户明确“继续下一段”才推进。验收问题优先在当前段修复。
- 每段包含该场景必要的 UI、接口、权限、持久化、状态和待办；涉及写入须同时覆盖 runtime / Prisma 与重复请求。
- 沿用界面风格，不新增无关功能；历史快照与主数据分开，只有明确要求才回填历史。
- 每段补充业务测试、执行 `make ci`，有条件时验证真实页面。未经明确安排不发布、部署、合并或打标签。
- 原需求文档的“仅收集”说明已由本次开发指令取代。R09-03 明确把 R07 的自定义字段规则扩展到产品库，按后续确认执行，不再重复询问。
