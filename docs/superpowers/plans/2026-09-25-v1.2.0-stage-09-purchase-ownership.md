## 验收反馈补充：既有直营采购单

- [x] 既有直营销售单产生的待认领采购单也必须先由采购主管、老板或管理员明确分配负责人，采购员不能靠改下拉框直接认领。

> 只针对仍处于草稿/待认领、且尚无锁定负责人的直营来源采购单；页面提供一次性分配入口，接口同时阻止直接保存和提交。runtime 与 Prisma 都保存锁定负责人，不批量修改历史单据；分配前的待办转给主管节点，分配后跟随新负责人。

- [x] 采购详情页操作区收窄为连续单列，保存与认领提交按钮靠近填写区。

> 页面渲染测试覆盖主管和采购员的可见操作；本机内置浏览器本轮不可用，独立浏览器可打开登录页，但没有当前会话，未对登录后的真实单据完成视觉和点击验证。补充修改后 `make ci` 再次全绿，API 555 项测试通过。

- [x] 验收反馈：已分配采购单在“保存草稿 / 认领并提交”区域只读展示负责人，不再显示可编辑下拉框；草稿接口拒绝变更负责人。

> 原页面即使采购员只能选自己，仍给出可编辑外观；旧单据还允许主管通过草稿保存变更负责人。现统一把负责人变更限定在分配节点，runtime 与 Prisma 都校验，采购员也不能提交别人的未锁定旧单据。已存在单据不批量改写。最终 `make ci` 全绿，API 556 项测试通过；本轮未获得已登录浏览器会话，未实操页面点击。
