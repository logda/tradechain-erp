# 第 13 段：系统内多页签工作区

范围：R13-01～R13-02。用户要求第 10～13 段开发完成后统一验收。

- [x] 在正式工作台既有页面外壳加入页签，按页面路径去重，支持切换与关闭。
  > 实际结果：页签沿用 Next 内部导航；新页面追加页签，同一路径只保留一个。关闭当前页签时进入相邻页面；最后一个页签回到正式首页。
- [x] 同一浏览器标签页内记住页签，并按登录身份隔离。
  > 实际结果：使用浏览器 `sessionStorage` 保存页面路径和简短标题；不同用户/角色分开。页签切换重新进入路由，页面表单未保存内容不会自动保留。
- [x] 执行页面交互与 `make ci` 门禁。
  > 实际结果：Codex 内置浏览器登录管理员和采购演示账号，验证打开第二页、切换、同页去重、关闭当前页签及不同角色页签隔离；采购待办可打开样品单详情。`make ci` 通过，Shared 16 套/42 项、Web 75 套/390 项、API 109 套/576 项。未在真实 Prisma/MySQL 浏览器环境验证。
