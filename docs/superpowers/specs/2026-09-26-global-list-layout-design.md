# 全局筛选与页面导航精简

## 本次范围

按用户反馈，将现有列表筛选独立为栏目，默认折叠；移除页面顶部的返回与便捷跨模块跳转栏。沿用现有卡片、字体、边框和间距。

## 决策

| 项目 | 实施方式 |
| --- | --- |
| 筛选展开 | 共享 FilterPanel 使用原生 details/summary，默认不设置 open；输入保持挂载，收起不丢失输入 |
| 独立栏目 | 产品库、往来单位、待办、日志接入同一组件；业务列表沿用共享组件 |
| 导航精简 | 移除活路由页面的返回、进入需求/报价模块等顶部便捷链接及空容器 |
| 保留入口 | 左侧导航、工作区页签、新增/编辑/审批动作和关联单据追溯链接 |
| 数据与权限 | 不修改查询口径、业务状态、页面/API 权限和存储结构 |

## 验证

组件测试验证默认收起、展开/收起、输入保留与表单提交；页面测试验证返回链接消失、业务入口仍在。运行 make ci，并在内置浏览器只读检查布局和实际查询。
