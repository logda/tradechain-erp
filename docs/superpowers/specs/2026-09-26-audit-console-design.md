# 审计中心与服务端排错日志

## 范围与决策

- 审计中心仅显示动作、操作人、字段变更、操作时间四列；沿用模块筛选、分页及审计查看权限。
- 动作和已有业务字段使用中文；明细行逐字段显示原值 → 新值。较长记录折叠其余变更，展开可查看全部。
- 复用原审计快照，兼容 runtime 与 Prisma；不回填历史、不改变持久化结构。
- 单据详情审计表保持原展示，四列表格仅用于审计中心。
- API 服务控制台记录请求路径、状态码、耗时；校验失败记录警告，服务异常记录堆栈。沿用原 HTTP 错误响应。
- Web 公共保存操作和审计加载失败输出服务端控制台，页面不显示排错日志。
- 请求日志不记录查询参数、请求正文或会话头。业务审计快照不展示密码、令牌或密钥字段。
- 不发布、不部署、不打版本标签。
